# Keep Dialog open until the operator exits

After an action finishes, display its outcome in a window with an OK button. Leave the window open until the operator acknowledges it, then return to the previous menu. Cancelling a submenu returns to its parent. The application exits intentionally when the operator chooses Exit.

## Review check

Verify that the outcome window does not auto-dismiss, OK returns to the correct menu, and completing a run does not exit Dialog.
