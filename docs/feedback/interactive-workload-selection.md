# Show all workloads in Interactive mode

Interactive currently lists only local core workloads. Let the operator see and select the individual checks and workloads available through Discovery, Standard, and Extended. Keep prerequisite labels short, such as `DVD required` or `SMB target required`. Selection alone does not grant device or peer authorization.

## Review check

Verify the menu lists the applicable work from all three modes and that the prerequisites remain readable in a terminal.
